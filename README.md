# Телеграмм бот, "Финансист"


Telegramm бот на Python с подключенной нейросетью. 

## Описание

Бот представляет собой нейроконсультанта для просмотра курса валют, генерации рекомендаций по финансам и отчетностью по личным финансам


**Основные функции:**
* "Регистрация в телеграм боте";
* "Курс валют";
* "Советы по экономии";
* "Личные финансы";

## Требования

* Python 3.10 или выше;
* стандартная библиотека Python (включая `telebot`).
