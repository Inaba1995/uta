# UTA

Telegram-бот для учёта финансов на Aiogram.

## Цель проекта
Разработать бота для отслеживания личных финансов.

## Задачи
- Регистрация пользователей
- Добавление доходов и расходов
- Ведение истории операций

## Результат
Бот, который записывает доходы/расходы и показывает историю операций.

## Стек технологий
- Python, Aiogram 3
- SQLite

## Запуск
```bash
pip install aiogram
python main.py
```
